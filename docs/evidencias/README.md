# Evidências reais do uso de IA generativa

Este registro acompanha o código criado nesta sessão de desenvolvimento com o Codex. Ele distingue requisitos recebidos, trabalho realizado e pendências. Não é uma transcrição integral do chat e não comprova gravação ou publicação que não ocorreram.

| Material | Conteúdo |
| --- | --- |
| `01-prompt-original.txt` | Cópia integral do arquivo de texto enviado pelo usuário com a especificação do projeto |
| `02-processo.md` | Decisões, código criado/revisado com IA e erros reais encontrados/corrigidos |
| `03-validacao.md` | Comandos, resultados e escopo da validação final nesta máquina |
| `testes/` | Relatórios reais gerados pelos testes, incluindo a primeira execução E2E com falhas |
| `capturas/` | Capturas feitas pelo Playwright na aplicação real com exemplos fictícios |

O autor humano deve apresentar a própria experiência e pode complementar essas evidências com capturas desta conversa. Nenhuma conversa adicional foi inventada. O prompt original foi preservado sem reescrita; os demais documentos são relatórios elaborados durante a implementação.

As capturas e os testes de navegador usam data fixa **02/11/2026, 12h em America/Sao_Paulo**, para que a demonstração e as asserções sejam reproduzíveis. Isso não altera o relógio do computador nem o funcionamento normal do app, que usa a data local do navegador. Capturas automatizadas não são um vídeo narrado nem testes de uma URL pública.
